This project is a creative and visually appealing web page designed to showcase various works and projects. It features smooth scrolling, interactive elements, and a modern design. The project utilizes GSAP for animations and Locomotive Scroll for smooth scrolling effects.

Project Structure
The project consists of the following files:

index.html: The main HTML file that contains the structure of the web page.
style.css: The CSS file that styles the web page.
script.js: The JavaScript file that adds interactivity and animations to the web page.
Features
Loading Animation: A loading screen with animations using GSAP.
Smooth Scrolling: Smooth scrolling effects using Locomotive Scroll.
Interactive Elements: Elements that change the background image of a section on hover.
Scroll to Top: A button to scroll back to the top of the page.
Dependencies
GSAP: A JavaScript library for creating animations.
Locomotive Scroll: A smooth scrolling library.

File Descriptions
index.html
The main HTML file that contains the structure of the web page. It includes sections for loading, navigation, and different pages with interactive elements.

style.css
The CSS file that styles the web page. It includes styles for the loading screen, navigation bar, pages, interactive elements, and footer.

script.js
The JavaScript file that adds interactivity and animations to the web page. It includes GSAP animations for the loading screen, Locomotive Scroll initialization, and event listeners for interactive elements.
